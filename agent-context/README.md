# Communication Engineering Operational Context

This directory is the human-maintained operational briefing derived from the Communication Engineering research corpus.

It is intentionally smaller and more conservative than the research repository.

## Start here

1. `COMMUNICATION-FOUNDATIONS.md`
2. `COMMUNICATION-DECISION-CHECKLIST.md`
3. `PURPOSE-OUTCOME-MATRIX.md`
4. `COMMUNICATION-ANTI-PATTERNS.md`
5. `RESEARCH-STATUS.md`

## Boundary

The operational context contains:

- supported foundations that are ready for bounded use;
- provisional strategies clearly marked as provisional;
- research-status constraints preventing unsupported promotion.

It does not make writer personas, literary voices, or research examples into automatic style rules.

## Intended use

Use this context to help:

- plan communication;
- draft;
- rewrite;
- review;
- evaluate;
- hand off communication work.

The first release is a research source, not yet a packaged lifecycle product.

Packaging should follow only after prospective validation shows that the briefing improves real communication work without creating unnecessary ceremony or context burden.
