# Compact Communication Preflight

Use this only to decide whether the request is sufficiently specified before drafting.

1. Separate **known source facts** from **communication decisions**.
2. Look only for missing information that could materially change:
   - purpose or requested action;
   - audience segment, role, or prior state;
   - decision/approval authority;
   - proof or evidence obligation;
   - material uncertainty or stakes;
   - channel/use event;
   - accessibility or safe personalization.
3. Do not ask for information already supplied.
4. Do not invent an audience, owner, approval, deadline, preference, accessibility need, or recipient state.
5. Group related missing fields into the smallest useful clarification set.
6. If safe progress is possible, provide a reversible bounded default:
   - neutral status/update;
   - non-personalized form;
   - explicit assumption;
   - provisional brief.
7. If the request is already sufficiently specified, get out of the way and draft normally.

Return useful work, not a completed form. Unknown remains unknown unless the source supports an inference.
